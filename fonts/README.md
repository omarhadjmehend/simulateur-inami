# Polices

Titres et montants. Le texte courant utilise la police du système (zéros sans barre, rien à télécharger). Intégrées à la page par `build.js` (aucun appel à Google Fonts) : sous-ensemble « latin », qui couvre le français, le néerlandais, € et −.
